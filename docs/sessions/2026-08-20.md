## What is genuinely good and must be preserved

- **I4 is properly done.** One `Pipeline`, raw frame in, probability out, logged
  and loaded as a unit. No train/serve skew.
- **The threshold travels with the model.** `train.py` sweeps cost on
  out-of-fold predictions and tags the run; `predict.py:29-49` reads it back and
  reports `threshold_source`, so an accidental 0.5 is visible rather than silent.
  `config.py:38-51` refuses to let an unset variable masquerade as a choice.
  This is better than the reference plan asks for. Keep it.
- Pinned categories + `handle_unknown='ignore'` (`preprocess.py:28-30`).
- Median impute inside the Pipeline; no `dropna`, no `fillna(0)`.
- The UI already talks to the API over HTTP only, never importing the model.
